## Authenticity and spam

Do not:

- send bulk, aggressive, unsolicited replies, mentions, or DMs;
- post duplicate or near-duplicate content or repeat link-only messages;
- reply with content unrelated to the original post;
- use excessive or unrelated hashtags to redirect attention;
- coordinate likes, replies, reposts, follows, views, or other engagement;
- buy engagement, use follow churn, or indiscriminately follow accounts;
- use unauthorized automation, fake identities, impersonation, or deceptive
  media;
- edit a post or destination URL deceptively to reuse existing engagement.

The target is authentic, topic-relevant participation, not a maximum activity
rate. A reply can be spam even when it is manually written if it is repetitive,
irrelevant, or aggressively distributed.

## Execution guardrails

- Keep draft, queued, and published states separate.
- Require explicit authorization for the current live batch and account.
- Use the smallest useful batch and pause if the account receives a warning,
  challenge, spam label, unexpected rate limit, or security alert.
- Never share passwords, cookies, tokens, or private messages in a draft or
  log.
- Verify the public permalink, account, parent post, exact text, media, and
  link after publishing.
- Treat deletion, edit, failed submission, and partial thread publication as
  states to record—not as silent cleanup.

X's technical limits are not engagement targets. Policy compliance can be
stricter than a numeric limit, and limits may vary by account state or change
over time.

## Measurement contract

For each action, log:

| Field | Requirement |
| --- | --- |
| Identity | Account, author, target post, audience/lane |
| Content | URL, timestamp, format, text version, media, CTA placement |
| Evidence | Proof source, claim status, link destination |
| Experiment | Hypothesis, cell, primary metric, guardrails |
| Snapshot | 24–72h metrics and later read if needed |
| Outcome | Qualified replies, profile visits, clicks, follows, downstream event |
| Interpretation | Observation, inference, decision, next test |

Useful organic signals include impressions/views, engagements, engagement rate,
replies, reposts, likes, follows, profile clicks, link clicks, and video
retention/view/completion where available. Define which signal represents the
objective before posting.

Do not equate impressions with unique people, views with attention, likes with
trust, or clicks with activation. X view counts can include repeat views and
the author's own view, so treat them as reach context rather than unique reach.

## Evidence and attribution

Separate:

- **Observed:** the metric or public interaction visible in X analytics or the
  public post;
- **Attributed:** a downstream event with a reliable link, analytics event, or
  explicit user report;
- **Inferred:** a plausible explanation that still needs testing;
- **Unknown:** a gate not observed.

For organic experiments, compare like with like: topic, target-post reach,
account age, asset, CTA, timing, and audience. For paid campaigns, keep paid
metrics separate and use X's campaign/conversion measurement rather than
claiming organic causality.
